> The full specification is in [docs/spec/](docs/spec/README.md). This file is kept as the original idea.

## Features

- API Catalogue - Open API, Async API
- API Explorer
- Developer tools - CLI, CI/CD integration and workflows
- Version diff
- API Linter - best practices audit, specs and quality checks
- API Security Audit
- Versioning - release management
- Tracing
